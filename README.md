# AWS S3 File Uploader

A Python CLI application for managing small business file backups to AWS S3 (ICTPRG302 Assessment Task 3).

## Setup Instructions
1. Clone the repository and open it in VS Code.
2. Create and activate a virtual environment:
   `python -m venv .venv`
3. Install dependencies:
   `pip install -r requirements.txt`
4. Copy `config.json.example` to `config.json` and insert your AWS Learner Lab credentials.
5. Run the application:
   `python src/uploader.py`
